# Global Ecosystems Atlas - Feedback & Issues Tracking

Thank you for your interest in the Global Ecosystems Atlas! We welcome your feedback on issues, bugs and would love to hear from you about how to make the Atlas better for everyone. 

## Reporting an Issue

Issues can be logged in this repository. Click [here](https://github.com/Global-Ecosystems-Atlas/feedback/issues) to create a new issue or view existing issues.

Before creating a new issue, please check and consider the following:

* Does the issue already exist?
* You have selected the appropriate template for a bug report, feature request, or general feedback
* If you have *feedback or a suggestion*, please provide detailed information as to what could be improved and how would it work. 
* If discovered an *issue or a bug*, please describe it as thoroughly as possible by providing screen captures or steps to reproduce the issue. 

## Status of Issues

Issues will have one of the following statuses:
* **bug** Have you spotted a bug in our code? Perhaps a function that doesn't work properly. If so, add this label to your issue request!
* **feature request** - Add Description - 
* **correction required** - Add Description - 
* **planned feature** - Add Description - 
* **Not under consideration** - Add Description -
